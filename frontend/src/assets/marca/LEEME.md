# Marca TechAsset

Assets del logo definitivo (etiqueta de activo). El detalle de construcción, colores y reglas
de uso está en `imagenes/LEEME - marca.md`, en la raíz del caso.

- `logo-marca.svg`: marca suelta, para favicon y avatar.
- `logo-horizontal.svg`: lockup para fondos claros.
- `logo-horizontal-oscuro.svg`: lockup para fondos oscuros.
- `logo-horizontal-monocromo.svg`: una tinta.

El wordmark está trazado a curvas: los SVG no dependen de la fuente instalada. En la interfaz,
el lockup se compone con el componente `MarcaTechAsset` y texto real para que sea accesible.
